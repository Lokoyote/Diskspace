# Disk Space
!(https://github.com/Lokoyote/Diskspace/blob/main/Diskspace%20screenshot.png)

GNOME Shell extension displaying the usage percentage of a selected filesystem in the top panel.

## Features

- Shows the usage percentage in the top panel
- Lets you choose which mounted filesystem to monitor
- Lists all mounted filesystems in the menu
- Updates automatically when mounts change
- Optional custom color for the progress bar and its usage text in the menu (follows the shell theme by default; the red warning above 90 % is kept; the panel indicator is not affected)

## Requirements

- GNOME Shell 45+
